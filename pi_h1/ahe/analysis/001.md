## Generic harness fixes
- Enforce **incremental compile/run gates** after each substantial edit; block further edits if parse fails.
- Add **file snapshot/rollback** before destructive operations; disallow delete/overwrite of sole source without backup.
- Require **test verdict consistency checks**: if stderr/warnings contain parse/runtime errors or contradictory “Correctly raised error” + FAIL, mark run invalid for self-claimed success.
- Encourage **minimal targeted patches** over full rewrites once a partially working baseline exists.

## Regression risks
