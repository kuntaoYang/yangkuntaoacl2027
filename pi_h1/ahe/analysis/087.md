## Generic harness fixes
- Provide a **binary-analysis skill/playbook** that enforces: observe → hypothesize → test → update, with explicit tracking of confirmed vs inferred facts.
- Add middleware checks that flag repeated speculative claims unsupported by the latest tool outputs.
- Ensure a minimal standard toolkit for reverse-engineering tasks (or expose equivalent built-in tools) so absence of `file/strace/gdb` does not force brittle improvisation.
- Add completion guardrails: if no evidence of result-file write exists after substantial exploration, force a plan refresh focused on end condition.
