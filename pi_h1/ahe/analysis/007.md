## Generic harness fixes

- Provide a **legacy-build environment skill** or middleware recipe for common compatibility layers (protobuf compiler, Boost, OpenCV, HDF5 include/lib path quirks, apt noninteractive flags).
- Add **package-install middleware** that:
  - uses noninteractive apt defaults,
  - detects interrupted dpkg states,
  - runs standardized recovery once,
  - avoids repeated concurrent/overlapping apt invocations.
- Add **artifact-progress checks** after major phases: build success, dataset existence, solver modifications applied, training started, output/model files present.
- Add a **task-state checklist memory** so recognized requirements (e.g., CPU-only, exactly 500 iterations, output path) must be verified as completed, not just mentioned.
