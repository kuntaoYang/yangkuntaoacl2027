## Generic harness fixes
- Preinstall or provide a known-good **fastText CLI** (or compatible Python env) for tasks requiring it.
- Add middleware guidance to **prefer a working CLI fallback** once verified, instead of continuing package-install retries.
- Add a lightweight harness skill for **safe file-generation patterns** (e.g., avoid shell-variable interpolation inside quoted here-doc Python).
- Encourage/checkpoint a “minimal end-to-end run” after environment recovery before further optimization.

## Component choice
Primary components implicated:
- **Tool implementation / environment**: missing compatible `fasttext` package path.
- **Middleware**: no strong policy to pivot to the verified CLI path.
- **Skill**: brittle script authoring for shell/Python interop.

## Regression risks
- Forcing stronger CLI preference could hurt tasks where Python APIs are required.
- Preinstalling packages may mask portability issues across tasks.
- Auto-generated script templates can reduce these interpolation failures, but overly rigid templates may limit flexibility on atypical data-prep tasks.
