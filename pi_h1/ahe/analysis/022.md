## Generic harness fixes
- Provide a **verified environment manifest** at runtime (e.g., whether Python exists, what bioinformatics binaries are installed). This would likely prevent the repeated failed Python attempts (**steps 3, 27**).
- Add a **sequence-analysis skill/tool** for FASTA parsing, circular alignment/diff, reverse complement, and edit extraction. The bash improvisation was error-prone (**steps 7–14, 17, 19–21, 36, 38, 41**).
- Add a **primer-design/Tm tool wrapper** around the required oligotm settings, so the agent can validate constraints instead of reasoning informally (**task requirement in step 1; absence throughout steps 30–41**).
- Add a completion check in middleware: if the task requests an output file, verify that a write occurred before ending.

## Component choice
Primary issues are in:
- **Tool description**: environment capabilities unclear.
- **Tool implementation**: missing high-level bio sequence / Tm utilities.
- **Middleware**: no guardrail for required artifact creation.
Secondary:
- **Skill**: lack of reusable procedure for “compare plasmids → derive edit → design validated SDM primers”.

## Regression risks
- Adding stronger tool affordances may increase overreliance on wrappers and reduce flexibility on simpler text-only tasks.
- Completion checks could cause longer runtimes if agents loop trying to satisfy file-output requirements.
- If a bio-skill over-abstracts, it may obscure failure modes unless intermediate evidence (edit coordinates, annealing spans, Tms) is surfaced.
