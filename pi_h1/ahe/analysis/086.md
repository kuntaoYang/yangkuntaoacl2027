## Generic harness fixes
- Preflight check and surface actual installed Python packages/utilities before coding.
- Enforce dependency policy in middleware: block or warn on imports outside allowed libraries before execution.
- Add lightweight CV-analysis skills/templates: inspect background subtraction quality, foreground bbox trajectory, centroid/foot-contact proxies, and produce diagnostic summaries before finalizing.
- Encourage checkpointed evaluation: require the agent to justify algorithm stability if outputs for the same input change materially across revisions.
