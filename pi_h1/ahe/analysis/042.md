## Generic harness fixes
- Add a **verification gate**: before final response, require a single canonical evaluation readout for all deliverables and block success language unless all thresholds pass.
- Add a **structured analysis skill** for optimization tasks: extract constraints, evaluator semantics, and current-best table before experimentation.
- Add **trajectory self-consistency checks**: flag contradictions between earlier metrics and final claims.
- Limit long exploratory loops by requiring periodic “best-known candidate + why rejected” summaries.
