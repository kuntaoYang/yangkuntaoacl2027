## Generic harness fixes

- Add a **final-answer validator** that checks whether the output matches the requested schema/format before write-out (here, coordinate move syntax rather than algebraic notation).
- Add a **self-consistency check** for image-derived structured state: if the model shows uncertainty about side to move or board contents, require either re-reading/zooming or explicit abstention/escalation rather than committing.
- Encourage **grounded extraction before reasoning**: first enumerate board squares/pieces in a structured form, then derive moves, instead of mixing uncertain perception with chess analysis.
- Optionally add a generic **legality/format verification middleware** for tasks requiring structured moves.

## Component choice
Primary: **middleware**  
Secondary: **prompt** and **skill**

- **Middleware:** best place for schema validation and confidence gating.
- **Prompt:** can remind the agent to output only coordinate notation and verify against task instructions.
- **Skill:** a reusable “extract board state / verify move format” skill could improve robustness.

## Regression risks

- Over-strict validation may increase abstentions on tasks where approximate natural-language answers are acceptable.
- Additional verification steps may increase latency/token use.
- If confidence gating is too aggressive, the agent may fail more often on solvable vision tasks instead of attempting an answer.
