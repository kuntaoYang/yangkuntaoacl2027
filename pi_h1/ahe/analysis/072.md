## Generic harness fixes
- Add a **schema conformance check** early: validate `/app/re.json` is a JSON list of 2-item arrays, not dicts.
- Add a **generalization gate** before submission: test on several unseen positions, not only the exemplar and one PGN.
- Add a **trajectory watchdog** for excessive debug-script churn / repeated syntax or API errors, prompting a strategy reset sooner.

## Component choice
- **Prompt**: emphasize that exact-position memorization is invalid for tasks requiring general correctness.
- **Middleware**: add automatic artifact validation (JSON shape, size, and a few randomized holdout checks).
- **Skill**: improve structured debugging / API usage discipline for Python-chess and regex substitution semantics.

## Regression risks
- Tightening against overfitting may reduce performance on tasks where exemplar-specialization is acceptable.
- Schema validators could reject creative but valid encodings if too rigid.
- More aggressive strategy-reset heuristics may interrupt productive exploration on genuinely hard tasks.
