## Generic harness fixes
- Require a **structured acceptance checklist** before finalization: verify target file path, residual threshold, and benchmark threshold with explicit printed outcomes.
- Add middleware that flags **silent test commands** as non-evidence unless stdout/stderr contains explicit pass/fail markers.
- Add a “final artifact guard” that warns when experimentation shifts to files other than the required entrypoint.
- Encourage a **stop condition** after repeated negative controls on speed to avoid unbounded speculative rewrites.

## Primary component choice
- **Middleware** (highest leverage): evidence gating, artifact-path checks, and final-validation enforcement.
- Secondary: **Memory/skill** (task-state tracking and disciplined validation workflow).

## Regression risks
- Stricter evidence gating may reduce flexibility for tasks where tests are intentionally quiet.
- Artifact-path enforcement may block useful side experiments unless sandbox files are explicitly allowed.
- Early stop rules could prevent recovery on tasks where one late pivot genuinely works.
