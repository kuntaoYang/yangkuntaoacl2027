## Generic harness fixes
- Add a **schema validator** for artifact files that checks declared column semantics against the agent’s internal edge tuples before finalization.
- Provide a **stable preinstalled causal/BN stack** or pinned examples for supported APIs to avoid exploratory debugging.
- Add a reusable **causal intervention skill** that defines graph-update conventions explicitly and separately from sampling.
- Add a final **artifact self-check stage**: parse produced CSVs, verify edge count, acyclicity, root constraints, and requested row count.

## Regression risks
- Tightening CSV validation may expose many previously hidden “looks plausible” failures.
- Forcing a canonical intervention convention could break tasks that accept alternative but mathematically reasonable conventions unless prompt/tool docs specify one.
- Pinning libraries may reduce flexibility across environments but should greatly improve reliability.
