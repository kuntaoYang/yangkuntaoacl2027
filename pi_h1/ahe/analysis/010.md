## Generic harness fixes
- Require **artifact-first checkpoints**: after any file write, immediately run a minimal validation loop and block further ideation if the artifact is placeholder/untested.  
- Add **trajectory guardrails against speculative resets**: detect repeated “new approach” pivots without improved metrics and force summarization of what is already disproven.  
- Add **syntax/error-recovery middleware**: when consecutive script errors occur, require simplification or smaller verified subroutines before continuing.  
- Encourage **capability-aware decomposition**: if the model only has a high-level algorithm, require proving one concrete gate-level primitive before generating large files.

## Component choice
- **Prompt**: strongest lever; the agent needed stricter instructions to avoid placeholder outputs and repeated resets.  
- **Middleware**: useful for enforcing validation checkpoints and detecting unproductive churn.  
- **Skill**: secondary; a reusable “generate-and-verify artifact” skill could help.

## Regression risks
- Over-constraining validation loops may slow successful creative synthesis tasks.  
- Anti-churn stopping rules could prematurely halt exploration on tasks that genuinely require several algorithm pivots.  
- Syntax-recovery gating may increase token/tool use on otherwise solvable tasks.
