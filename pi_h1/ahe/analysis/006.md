## Generic harness fixes

- Add **middleware guardrails** for long web-search loops: cap repetitive remote-search attempts and require a state change (e.g., verified archive, extracted tree, build start) every N steps.
- Add **tool/middleware-level artifact validation**: after download, automatically verify content type, size sanity, and archive integrity before the agent can treat a file as a source archive.
- Add **prompt/skill guidance** for retrieval tasks: when blocked by external sources, summarize verified blockers early and seek alternative sanctioned paths rather than repeating similar queries.
- Add a **memory/state heuristic** to detect repeated failures against the same domains/services and trigger escalation or termination.
