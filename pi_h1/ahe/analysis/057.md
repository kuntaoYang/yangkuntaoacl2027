## Generic harness fixes
- Add a **pre-write / pre-final assertion checklist**: before writing output, verify every explicit constraint from the user prompt against the candidate; if any fail, do not submit.
- Add **loop control / search diversification policy**: after N failed near-duplicate searches, require a new hypothesis or explicit declaration of insufficient evidence.
- Normalize tool availability or document minimal forensic utilities more clearly to reduce wasted probing.

## Primary component choice
- **Prompt** (primary): needs stronger instruction hierarchy around explicit constraint satisfaction and contradiction handling.
- Secondary: **Middleware** for final-answer validation gate against extracted task constraints.

## Regression risks
- Hard validation gates may increase false negatives on tasks where partial outputs are useful.
- Stronger anti-loop controls could prematurely stop productive iterative forensic work.
- If prompt pressure against contradiction is too strong, the agent may become overly conservative and avoid submitting valid-but-uncertain findings.
