## Generic harness fixes
- Provide a **reliable binary-inspection skill** or standard utility set for recovery tasks, so the agent need not improvise from raw `od` output.
- Add middleware checks requiring the agent to **validate extracted records** before concluding success (e.g., consistency checks, artifact existence/content checks).
- Add a prompt/harness rule to separate **observed bytes** from **hypothesized decoding**, discouraging unsupported extrapolation after partial evidence.
- Add automatic recovery from script failures: when Python exits with syntax/runtime errors, require a shorter corrected repro rather than another large speculative script.
