## Generic harness fixes
- Add a **date-constraint verification check** before finalizing answers; if selected evidence is newer than requested cutoff, force abstain/escalate.
- Provide a **stable leaderboard access helper** (or middleware wrapper) returning benchmark rankings with snapshot date and “complete tasks only” already resolved.
- Add a **consistency guard**: if agent falls back from official API to ad hoc aggregation, require explicit uncertainty and prohibit final answer unless equivalence is verified.
- Surface **schema examples** for common result formats (`main_score`, split lists, task counts) to reduce repeated parsing failures.
