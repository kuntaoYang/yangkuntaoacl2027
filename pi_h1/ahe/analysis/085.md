## Generic harness fixes
- Add **schema-aware MJCF validation** before running full evals, surfacing valid attributes/enums for MuJoCo XML.
- Provide a **stable tuning skill/workflow**: edit → validate XML → run official evaluator subset → record results in a table.
- Encourage/automate use of the **official eval script as the ground truth** rather than ad hoc timing scripts.
- Add lightweight **result memory** so tested configurations and measured outcomes are tracked, avoiding repeated dead ends.
