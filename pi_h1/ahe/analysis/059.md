## Generic harness fixes
- Add **contract-aware validation**: automatically test candidate outputs in isolation with referenced artifacts removed, especially when the prompt forbids dependence on generated files.
- Add **dependency scanning** for suspicious reads of task-local outputs (e.g., `/app/image.ppm`) when the task requires independence.
- Require a pre-submission **constraint checklist** in middleware: “Does the solution depend on files created during analysis/run?” with a hard stop on contradiction.
- Distinguish **behavioral equivalence** from **artifact replay** in evaluator messaging and prompt scaffolding.

## Component choice
- **Middleware** (primary): validation should enforce isolation and dependency constraints.
- **Prompt** (secondary): emphasize that matching a generated artifact by reading it is non-compliant.
- **Skill** (tertiary): stronger reverse-engineering workflow under limited tools.

## Regression risks
- Stricter isolation checks may reject some legitimate cache/data-file-based solutions in other tasks unless exceptions are explicit.
- Stronger anti-artifact-replay rules could over-penalize tasks where reading provided fixtures is allowed; prompts/evaluators must clearly separate allowed inputs from self-generated intermediates.
